# City catalog expansion

The game catalog contains 150 unique city names: 50 state capitals, the original 50 additional cities, and 50 exploration cities. This is a curated learning aid, not an exhaustive US city database.

The 50 additions below were matched by name and state against the U.S. Census Bureau's [2025 Places Gazetteer](https://www.census.gov/geographies/reference-files/time-series/geo/gazetteer-files.2025.html), [national source archive](https://www2.census.gov/geo/docs/maps-data/data/gazetteer/2025_Gazetteer/2025_Gaz_place_national.zip), on 2026-09-27. Gazetteer geographic types include consolidated municipalities; Anchorage is listed as a municipality. Census statistical identifiers are retained here for reproducible matching. No population ranking is claimed.

Only these additions were checked in this pass. Existing entries retain their previous provenance. Places with the same normalized name in different states cannot both be represented by the current name-based game identity; this expansion avoids those duplicates.
